# 🎬 Movie Ticket Booking System

## 📌 Project Overview

The Movie Ticket Booking System is a full-stack web application developed using Python, Django, FastAPI, and MongoDB. It provides a convenient platform for users to explore movies, view available theaters, and book movie tickets online.

The application includes a user-friendly interface and a dedicated admin dashboard that allows administrators to manage movies, theaters, and shows efficiently.

## 🚀 Key Features

### 👤 User Features
- User Registration and Login.
- Secure User Authentication.
- Browse Available Movies.
- View Movie Details, Genres, Ratings, and Descriptions.
- Explore Theater Information and Locations.
- Book Movie Tickets.
- View Booking History.
- Cancel Existing Bookings.
- Manage User Profile.
- Change Password.

### 🔐 Admin Features
- Admin Login and Authentication.
- Admin Dashboard.
- Add, Edit, and Delete Movies.
- Manage Theater Information.
- Add, Edit, and Delete Theaters.
- Manage Movie Shows.
- View and Manage Bookings.
- Monitor Theater Seat Availability.

### 🎨 UI/UX Features
- Modern and Responsive User Interface.
- Attractive Login and Registration Pages.
- Interactive Navigation Bar.
- Responsive Layout for Desktop, Tablets, and Mobile Devices.
- CSS Hover Effects and Animations.
- User-Friendly Booking Interface.

## 🏗️ Project Architecture

The application follows a two-layer web architecture:

1. **Frontend (Django):** Handles webpage rendering, user interactions, session management, and communication with the backend.
2. **Backend (FastAPI):** Handles REST API requests, authentication, business logic, movie management, theater management, and ticket bookings.
3. **Database (MongoDB):** Stores user information, movies, theaters, shows, and booking records.

## ⚙️ Main Functional Modules

- User Management
- Movie Management
- Theater Management
- Show Management
- Ticket Booking
- Booking Cancellation
- Admin Dashboard

## 🎯 Project Objective

The main objective of this project is to develop a complete online movie ticket booking platform that simplifies the ticket reservation process and provides efficient management facilities for administrators.

It also demonstrates practical implementation of full-stack web development, REST API integration, database operations, authentication, and responsive frontend design.
